# 🤖 JARVIS MARK I

### An AI Voice Assistant(JARVIS) built with Python, Gemini AI and Speech Recognition.

## About

JARVIS MARK I - is an AI-powered desktop voice assistant inspired by Iron Man's JARVIS.

It can understand voice commands, control applications, search the web, answer AI questions using Gemini, play music, provide weather updates, save notes, take screenshots, and perform many desktop automation tasks.

The goal of this project is to build a professional AI assistant while learning real-world software engineering practices using Python, Git and GitHub.

## ✨ Features It Contains-

- 🎤 Voice Recognition
- 🔊 Natural Text-to-Speech
- 🌐 Google Search
- 🤖 Gemini AI Integration
- 🌦 Live Weather Information

## Installation

Clone the repository

```bash
git clone https://github.com/harshalrokade01/JARVIS-MARK-I.git
```

Navigate to the project folder

```bash
cd JARVIS-MARK-I
```

Install the required libraries

```bash
pip install -r requirements(Library).txt
```

Create a `.env` file and add your Gemini API key

```env
GEMINI_APIKEY=YOUR_API_KEY
```

Run the project

```bash
python main.py
```
